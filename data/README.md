# Data Guide

원자료는 데이터 제공기관의 이용조건을 고려하여 이 저장소에 포함하지 않습니다.

분석을 재현하려면 `data/`에 다음 파일을 준비합니다.

```text
학교안전사고 데이터.xlsx
2025_연도별 학생수.xlsx
2025_연도별 학교수.xlsx
```

`학교안전사고 데이터.xlsx`는 `2021`, `2022`, `2023`, `2024`, `2025` 시트를 사용하며 주요 컬럼은 다음과 같습니다.

```text
지역, 학교급, 사고자구분, 사고자학년, 사고자성별,
사고연월, 사고요일, 사고시간, 사고장소, 사고당시활동,
사고형태, 사고부위
```
